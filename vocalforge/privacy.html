VocalForge privacy

VocalForge is a static page. There is no VocalForge server, no account, no analytics and no tracking.

What stays on your device

  • Your API key is kept in this browser's local storage and never leaves it except as the authentication header on calls to the API host you configured.
  • Your lyrics and settings are saved in local storage so a refresh does not lose them.
  • Generated audio is saved in this browser's IndexedDB. Delete a take in the app, or clear the site's data in your browser, to remove it.

What leaves your device

When you press Generate, Draft lyrics or Check key, the page sends your lyrics, style settings and API key to the API host shown in Settings. By default that is ElevenLabs (api.elevenlabs.io), whose handling of that data is covered by the ElevenLabs privacy policy. If you point the host at your own relay, the same data goes through that relay instead.

Nothing else is sent anywhere.
